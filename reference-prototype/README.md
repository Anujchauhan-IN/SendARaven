# SendARaven — visual prototype 01

A responsive, frontend-only visual proof of concept for the **Raven Rookery**.

## Preview
From this directory run `python -m http.server 8000` (or any static server), then open `http://localhost:8000`.

## Included
- Textured parchment, wood-inspired sidebar, five provisional SVG raven illustrations
- Responsive rookery with three ready and two away states (fixture data)
- Working navigation to placeholder Flights and Inbox screens
- AI-generated parchment asset used as the direct typed and handwritten writing surface
- Typed input, finger/stylus drawing, per-page handwriting undo/redo and prototype page navigation
- Raven selection in composer

## Explicitly not implemented
Authentication, database, persistent drawing, real dispatch, flight map, notifications, wax seal personalization, accessibility audit and production artwork.

## Next milestone
Review mobile/desktop writing-screen screenshots and interaction behavior. The parchment treatment, typography and layout remain unapproved; raven artwork also still requires a cohesive production asset set.
