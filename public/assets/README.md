# Frontend assets

- `textures/parchment-portrait.svg` is a procedural, portrait-oriented parchment prepared for the writing-page proof. It is an original project placeholder, not a stretched or cropped version of the landscape reference image.
- Final texture, font, raven, seal and map assets still require provenance tracking, optimization and explicit visual approval.
